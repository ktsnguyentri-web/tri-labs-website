================================================================================
          HƯỚNG DẪN THÊM VÀ CẬP NHẬT BÀI VIẾT (WRITING / RESEARCH)
================================================================================

Thư mục `writing/` này là nơi bạn quản lý toàn bộ các bài viết (Essays, Notes & Research)
hiển thị trên trang chủ (mục 03. Writing) và trang lưu trữ (/writing).

Bạn có thể thêm bài viết mới theo 1 trong 2 cách cực kỳ đơn giản sau:

--------------------------------------------------------------------------------
CÁCH 1: TẠO THƯ MỤC RIÊNG (KHUYÊN DÙNG KHI CÓ ẢNH BÌA HOẶC NHIỀU ẢNH MINH HỌA)
--------------------------------------------------------------------------------
1. Tạo một thư mục mới bên trong `writing/`, đặt tên dạng slug tiếng Anh không dấu.
   Ví dụ:
   `writing/tri-tue-nhan-tao-trong-kien-truc/`

2. Bên trong thư mục đó, đặt:
   - File bài viết: `bai-viet.md` (hoặc `bai-viet.txt`, `index.md`)
   - File ảnh bìa: `cover.jpg` (hoặc `cover.png`, `cover.webp`)
   - Bất kỳ ảnh minh họa nào khác bạn muốn chèn vào bài viết.

3. Hệ thống sẽ tự động sao chép các ảnh vào website và ánh xạ link ảnh cho bạn!

--------------------------------------------------------------------------------
CÁCH 2: TẠO TRỰC TIẾP 1 FILE .MD TRONG THƯ MỤC WRITING/
--------------------------------------------------------------------------------
1. Tạo trực tiếp file `.md` trong thư mục `writing/`.
   Ví dụ:
   `writing/nghien-cuu-vat-lieu-moi.md`

2. Mở file và soạn thảo theo cấu trúc bên dưới.
