## Overview
SpaceSyntax Graph is an open-source spatial network topology engine. It calculates syntactic measures of urban masterplans and interior layouts, computing axial connectivity, visual depth, and pedestrian flow probabilities.

## Features
- **Isovist Field Generation**: Real-time 2D ray casting for spatial visibility calculation.
- **Topological Integration**: Graph shortest-path algorithms evaluating urban accessibility.
- **Agent-based Movement Simulation**: 10,000+ simultaneous pedestrian agents for wayfinding analysis.
