          HƯỚNG DẪN THÊM VÀ CẬP NHẬT CÔNG CỤ / NGIÊN CỨU (LABS & TOOLS)
================================================================================

Thư mục `tools/` này là nơi bạn quản lý toàn bộ các công cụ, sản phẩm thử nghiệm,
nghiên cứu tính toán (Prototypes, Computational Tools & Scripts) hiển thị trên:
- Trang chủ (mục 02. Labs)
- Trang lưu trữ (/tool hoặc /labs)

Bạn có thể thêm tool mới theo 1 trong 2 cách cực kỳ đơn giản sau:

--------------------------------------------------------------------------------
CÁCH 1: TẠO THƯ MỤC RIÊNG CHO TOOL (KHUYÊN DÙNG KHI CÓ ẢNH CHỤP GIAO DIỆN / DEMO)
--------------------------------------------------------------------------------
1. Tạo một thư mục mới bên trong `tools/`, đặt tên dạng slug tiếng Anh không dấu.
   Ví dụ:
   `tools/facade-optimizer/`
   `tools/bim-space-calculator/`

2. Bên trong thư mục đó, đặt:
   - File mô tả tool: `tool.md` (hoặc `tool.txt`, `index.md`)
   - File ảnh bìa / demo: `cover.png` (hoặc `cover.jpg`, `cover.webp`)
   - Các ảnh chụp giao diện, sơ đồ thuật toán, GIF động (nếu có).

3. Hệ thống sẽ tự động sao chép các ảnh vào website và liên kết vào bài viết cho bạn!

--------------------------------------------------------------------------------
CÁCH 2: TẠO TRỰC TIẾP 1 FILE .MD TRONG THƯ MỤC TOOLS/
--------------------------------------------------------------------------------
1. Tạo trực tiếp file `.md` trong thư mục `tools/`.
   Ví dụ:
   `tools/parametric-solar-solver.md`

2. Mở file và soạn thảo theo cấu trúc bên dưới.
